# Redis Fallback Monitoring Metrics and Alerts

## Metrics
- **Fallback Count**: Number of times the fallback mechanism was triggered.
- **Fallback Duration**: Time taken for the fallback to complete.

## Alerts
- **High Fallback Count Alert**: Triggered when the fallback count exceeds a predefined threshold.
- **Long Fallback Duration Alert**: Triggered when the fallback duration exceeds acceptable limits.

## Implementation
Ensure that your monitoring system is configured to track these metrics and set up alerts accordingly.
